# 织云系统 · 应用台账与资产控制台

面向多团队的应用资产管理系统：**应用台账**（全生命周期登记）+ **资产控制台**（分布、变更、风险红点）+ **配置档案**（按应用+环境管配置、密文管控、环境对比、版本回滚）+ **变更留痕**（配置改动流水与差异清单导出）。

## 一键启动

```bash
docker compose up -d --build
```

访问 http://localhost:8016 。首次启动自动建库并写入初始数据（4 条业务线、9 个账号、24 个应用，覆盖 在研/上线/维保/下线 全部状态，含缺负责人 / 缺环境变量的红点样例；配置档案内置「支付网关」「会员中心」的开发/生产多环境配置、历史版本与明文查看留痕样例）。

本地开发（不用 Docker）：

```bash
pip install -r requirements.txt
uvicorn app.main:app --port 8016
```

> 密文配置使用演示级加密（随机 nonce + HMAC，无第三方依赖）。生产部署请通过环境变量 `ZHIYUN_SECRET_KEY` 注入独立密钥，或替换 `app/crypto.py` 为 KMS / AES-GCM 方案。

## 功能与规则

- **应用台账**：应用挂所属业务线、负责人、集群、环境（开发/测试/预发/生产）、生命周期状态；列表支持业务线 + 负责人 + 环境 + 状态 + 关键字组合筛选。
- **生命周期状态机**：`在研 → 上线 → 维保 → 下线`，只能向前流转；**下线为终态**，状态与所有信息（含环境变量）只读。状态回退（如 维保→上线）会被拦截并返回具体原因。
- **唯一性**：同一业务线下应用名不能重复（创建/改名均校验，返回 409 及原因）。
- **资产控制台**：各业务线应用数分布（按状态分段）、近 7 天有变更的应用、环境变量缺失 / 缺失负责人的红点提醒。
- **越权防护**：普通成员仅能访问本业务线数据；访问其他业务线的应用或按其他业务线筛选返回 **403 错误态页面**（非空白页）。
- **变更留痕**：创建、信息变更、状态流转、环境变量修改均写入变更日志。

### 配置档案（按「应用 + 环境」）

- **配置项字段**：键、值、值类型（字符串 / 数值 / 布尔 / JSON，服务端校验）、生效范围（全局 / 服务级 / 实例级）、是否密文。
- **密文管控**：密文加密落库（`enc:v1:` 前缀 + HMAC 校验），列表、环境对比、历史版本等所有接口默认返回 `******` 脱敏值，数据库与版本快照中均无明文。
- **看明文强制二次确认**：点击「查看明文」必须填写理由，**由服务端强制非空校验**（仅前端拦截无效，直接调 API 同样 400），每次查看都写入只追加的留痕。
- **环境对比**：任选两个环境（如开发 ⇄ 生产），逐键给出 值不同 / 仅左 / 仅右 / 一致 结论并高亮，差异数量汇总，密文两侧仍脱敏。
- **版本与回滚**：每次保存（及回滚）生成一个只增版本，可查看任意历史快照；回滚 = 把旧版本内容**追加为新版本**，因此历史版本与历史留痕都不会被覆盖（回滚留痕会记录改前→改后）。应用已下线（终态）时配置只读。
- **编辑密文**：编辑时密文行默认「留空=保持原密文」（服务端以原值回填，伪造保持标记会被拒绝）；需要修改可填新值，或经理由确认取回明文后再改（取回动作同样留痕）。

### 变更留痕

- 配置的**每一次键级改动**（新增 / 修改 / 删除 / 回滚 / 明文查看）都可按业务线（管理员）、**应用**、环境、动作、**时间窗**查询流水：谁改的、改前值 / 改后值、版本、理由。
- 普通成员的流水强制收窄到本业务线，显式越权筛选返回 403。
- 一键**导出差异清单 CSV**（UTF-8 BOM，Excel 直开不乱码；密文值在导出中同样脱敏；对 `= + - @` 开头内容做公式注入转义）。

## 主要 API

| 方法 | 路径 | 说明 |
|---|---|---|
| POST | `/api/login` | 登录（`{"username": "zhangwei"}`） |
| GET | `/api/apps` | 台账列表，参数：`business_line_id` `owner_id` `environment` `status` `q` |
| POST | `/api/apps` | 新建应用（同业务线重名 → 409） |
| GET | `/api/apps/{id}` | 详情（越权 → 403） |
| PATCH | `/api/apps/{id}` | 修改信息（已下线 → 400） |
| POST | `/api/apps/{id}/status` | 状态流转（回退/终态 → 400 及原因） |
| PUT | `/api/apps/{id}/env-vars` | 整体替换环境变量 |
| GET | `/api/console/summary` | 控制台汇总（分布/近 7 天变更/红点） |
| GET | `/api/apps/{id}/config/envs` | 应用各环境配置概览（版本号/项数） |
| GET | `/api/apps/{id}/config/{env}` | 某环境配置列表（密文脱敏） |
| PUT | `/api/apps/{id}/config/{env}` | 保存配置 → 生成新版本 + 逐键留痕（无变化 → 400） |
| POST | `/api/apps/{id}/config/{env}/reveal` | 查看密文明文（**服务端强制 reason 非空并留痕**） |
| GET | `/api/apps/{id}/config-diff/{left}/{right}` | 两环境配置逐键差异 |
| GET | `/api/apps/{id}/config/{env}/versions` | 版本历史 |
| GET | `/api/apps/{id}/config/{env}/versions/{v}` | 历史版本快照（密文脱敏） |
| POST | `/api/apps/{id}/config/{env}/rollback` | 回滚到指定版本（追加新版本，不覆盖留痕） |
| GET | `/api/audit/configs` | 配置留痕流水：`business_line_id` `app_id` `environment` `action` `start` `end` |
| GET | `/api/audit/configs/export.csv` | 导出差异清单 CSV（同筛选条件，密文脱敏） |

认证：请求头 `X-Token: <登录返回的 token>`。

## 目录结构

```
app/
  main.py          # FastAPI 入口：台账 / 状态机 / 权限 / 控制台 / meta
  auth.py          # 认证、业务线越权校验（各路由共用）
  db.py            # SQLite 连接、表结构、状态机与配置常量
  crypto.py        # 密文配置的加密/解密（enc:v1 + HMAC）
  seed.py          # 初始数据（4 业务线 / 24 应用 / 全状态覆盖）
  seed_config.py   # 配置档案演示数据（多环境差异 / 版本 / 明文查看留痕，幂等）
  routers/
    config.py      # 配置档案：版本、回滚、脱敏、明文二次确认、环境对比
    audit.py       # 变更留痕：流水查询、CSV 导出
  static/          # 前端（原生 JS，无构建步骤）
docker-compose.yml
Dockerfile
```
